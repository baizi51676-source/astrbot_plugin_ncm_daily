# 网易云音乐助手 (astrbot_plugin_ncm_daily)

> ## ⚠️ 安全与时效提醒
> - **安全**：`MUSIC_U` 相当于网易云账号登录态，**请勿分享给任何人**（群聊、公开仓库、截图等都不行）
> - **时效**：`MUSIC_U` 会定期失效（通常**几周到几个月**，取决于登录设备与使用频率），失效后日推/歌单会获取失败或为空，**重新登录浏览器复制一份即可**，无需卸载重装插件

网易云音乐个人助手：**搜索音乐、每日推荐、个人歌单、点歌**，支持发送 **QQ 音乐卡片**（群里可直接点击播放）。

- 配置网易云 `MUSIC_U` Cookie 后，可获取**每日推荐**和**个人歌单**
- 点歌/搜索/音乐卡片受**白名单**控制（管理员始终可用；白名单留空 = 不限制）
- 纯标准库实现，**零第三方依赖**，Windows / Linux 通用

## 功能

| 能力 | 说明 | 需要 Cookie | 权限 |
|---|---|---|---|
| 搜索音乐 | 按歌名/歌手搜索，返回歌曲列表 | ❌ | 管理员/白名单 |
| 音乐卡片 | 把歌曲以 QQ 音乐卡片形式发到群里/私聊（NapCat 渲染） | ❌ | 管理员/白名单 |
| 点歌 | `点歌 [歌手 - ]歌名`，列出结果回复序号播放 | ❌ | 管理员/白名单 |
| 每日推荐 | 今日日推歌曲列表 | ✅ | 仅管理员 |
| 我的歌单 | 账号创建/收藏的歌单列表 | ✅ | 仅管理员 |
| 歌单详情 | 查看指定歌单的歌曲列表 | ❌ | 仅管理员 |

## 安装

从 Release 下载 zip，解压到 `AstrBot/data/plugins/`，然后在 WebUI 启用插件。

## 配置（可选）

1. 浏览器登录 [music.163.com](https://music.163.com)
2. 按 `F12` 打开开发者工具 → 切到 **Network（网络）** 面板
3. 随便点一个请求，在 **Request Headers → Cookie** 里找到 `MUSIC_U=xxxx`，复制 `xxxx` 部分
4. 在 AstrBot WebUI 的插件配置里填入 `music_u_cookie`（失效后重新复制更新即可）

其他配置项：

| 配置项 | 类型 | 说明 |
|---|---|---|
| `admin_only` | 布尔 | 「我的歌单」/歌单详情/每日推荐仅管理员可用（**默认开启**）；⚠️ 不建议关闭，可能泄露歌单与听歌偏好隐私 |
| `point_song_allowlist` | 数组 | 音乐功能白名单（**点歌/搜索/音乐卡片**）；留空 = 不限制（所有人都可用）；管理员始终可用 |
| `point_timeout` | 整数 | 点歌交互超时（秒，**默认 30**，最小 5）；超时后机器人**主动发消息提示**并退出 |

**管理员判定（使用 AstrBot 自带机制，无需在本插件配置）**：
1. AstrBot 配置页面（WebUI → 配置 → `admins_id` 管理员列表）中填写的 QQ
2. QQ 群主 / 群管理员
3. 其他支持 `is_admin()` 的平台管理员

不是管理员时，机器人会提示你前往 AstrBot 配置页面添加。

## 命令交互（@机器人触发）

```
我的歌单 / 歌单 / 查看歌单        → 列出你的歌单（仅管理员）
回复序号                         → 列出该歌单歌曲（每页最多 200 首）
回复序号 / 歌名                  → 播放对应歌曲（卡片）
更多 / 下一页                    → 查看下一批歌曲

点歌 歌名                        → 搜索并列出结果（白名单用户）
点歌 歌手 - 歌名                 → 带歌手搜索，更精准
回复序号                         → 播放对应歌曲（卡片）

日推 / 今日推荐                  → 列出今日推荐（仅管理员）
回复序号 / 歌名                  → 播放对应歌曲（卡片）
```

所有列表均以**合并转发（聊天记录卡片）**形式发出：聊天界面只显示一个卡片，不占屏、不被 QQ 折叠拆分，点开后是完整的列表内容；交互仅**发起者本人**可操作，其他人回复无效；点歌超时默认 30 秒（可配置），超时后机器人会**主动发消息提示**并退出。

## 使用示例（对话触发）

```
搜一下 周杰伦 的晴天
→ 工具返回歌曲列表，AI 排版展示

播放第 2 首
→ AI 调用 play_music 发送 QQ 音乐卡片 🎵

今天有什么推荐的歌？
→ 获取今日日推（需配置 Cookie + 管理员）

看看我的歌单
→ 获取个人歌单列表（需配置 Cookie + 管理员）

打开歌单 3778678
→ 查看该歌单的歌曲列表（管理员）
```

## LLM 工具

插件向大模型暴露以下工具（LLM 可通过对话自动调用）：

| 工具 | 功能 | 需 Cookie | 权限 |
|---|---|---|---|
| `search_music` | 搜索歌曲（歌名/歌手） | ❌ | 管理员/白名单 |
| `play_music` | 发送 QQ 音乐卡片 | ❌ | 管理员/白名单 |
| `get_daily_recommend` | 获取今日日推 | ✅ | 仅管理员 |
| `get_my_playlists` | 获取账号歌单列表 | ✅ | 仅管理员 |
| `get_playlist_detail` | 查看歌单歌曲详情 | ❌ | 仅管理员 |

## 注意事项

- 仅**只读**操作，不会修改你的歌单/账号
- 音乐卡片仅支持 NapCat / OneBot v11（aiocqhttp）平台；其他平台自动降级为网易云链接
- 搜索接口偶尔会返回其他歌手的同名歌曲，以搜索结果为准
- 请控制调用频率，避免触发网易云风控
