# 网易云日推及歌单查看 (astrbot_plugin_ncm_daily)

> ## 安全与时效提醒
> - **安全**：`MUSIC_U` 相当于网易云账号登录态，**请勿分享给任何人**（群聊、公开仓库、截图等都不行）
> - **时效**：`MUSIC_U` 会定期失效（通常**几周到几个月**，取决于登录设备与使用频率），失效后日推/歌单会获取失败或为空，**重新登录浏览器复制一份即可**，无需卸载重装插件

网易云音乐个人助手：**搜索音乐、每日推荐、个人歌单、歌单搜索、点歌、歌曲封面**，支持发送 **QQ 音乐卡片**（群里可直接点击播放）。

- 配置网易云 `MUSIC_U` Cookie 后，可获取**每日推荐**和**个人歌单**
- 「歌单」指令可**搜索他人的公开歌单**（按名称或歌单 ID），查看其完整歌曲列表
- 选歌列表的卡片头部会展示**封面图**（歌单用歌单封面，日推用第一首歌封面）；回复序号支持**多选**（如 `1 7 98` 连续播放多首）；点歌/搜索/封面/音乐卡片受**白名单**控制（管理员始终可用；白名单留空 = 不限制）
- 封面支持**低（500×500）/ 高（1600×1600）/ 原图（最高约 3000px）**三档分辨率（默认低）；超大歌单可选**分页浏览**（每 100 首一页）
- 纯标准库实现，**零第三方依赖**，Windows / Linux 通用

## 功能

| 能力 | 说明 | 需要 Cookie | 权限 |
|---|---|---|---|
| 搜索音乐 | 按歌名/歌手搜索，返回歌曲列表 | 不需要 | 管理员/白名单 |
| 音乐卡片 | 把歌曲以 QQ 音乐卡片形式发到群里/私聊（NapCat 渲染） | 不需要 | 管理员/白名单 |
| 点歌 | `点歌 [歌手 - ]歌名`，列出结果回复序号播放（最多 20 条，失败自动降为 10 条） | 不需要 | 管理员/白名单 |
| 歌曲封面 | 发送指定歌曲的封面图片（分辨率三档可选） | 不需要 | 管理员/白名单 |
| 每日推荐 | 今日日推歌曲列表（菜单头部含第一首歌封面） | 需要 | 仅管理员 |
| 我的歌单 | 账号创建/收藏的歌单列表 | 需要 | 仅管理员 |
| 歌单搜索 | `歌单 关键词` / `歌单 歌单ID`：搜索他人公开歌单并查看完整歌曲列表（最多 20 条结果，失败自动降为 10 条） | 不需要 | 管理员/白名单 |
| 歌单详情 | 查看任意公开歌单的歌曲列表（整单展示或分页浏览，头部含歌单封面，支持多选播放） | 不需要 | 管理员/白名单 |

## 安装

从 Release 下载 zip，解压到 `AstrBot/data/plugins/`，然后在 WebUI 启用插件。

## 配置（可选）

1. 浏览器登录 [music.163.com](https://music.163.com)
2. 按 `F12` 打开开发者工具 → 切到 **Network（网络）** 面板
3. 随便点一个请求，在 **Request Headers → Cookie** 里找到 `MUSIC_U=xxxx`，复制 `xxxx` 部分
4. 在 AstrBot WebUI 的插件配置里填入 `music_u_cookie`（失效后重新复制更新即可）

其他配置项：

| 配置项 | 类型 | 说明 |
|---|---|---|
| `admin_only` | 布尔 | 「我的歌单」/每日推荐仅管理员可用（**默认开启**）；不建议关闭，可能泄露歌单与听歌偏好隐私；「歌单」搜索跟随下方白名单 |
| `point_song_allowlist` | 数组 | 音乐功能白名单（**点歌 / 歌单搜索 / 歌曲封面 / 音乐卡片**）；留空 = 不限制（所有人都可用）；管理员始终可用 |
| `point_timeout` | 整数 | 点歌交互超时（秒，**默认 120**，最小 5）；超时后机器人**主动发消息提示**并退出 |
| `cover_quality` | 字符串 | 封面分辨率档位：`low`（500×500，**默认**）/ `high`（1600×1600）/ `original`（原图，最高约 3000px）。**高/原图档位会明显增加图片获取与发送的耗时、流量** |
| `playlist_paging` | 布尔 | 超大歌单**分页展示**（每 100 首一页，如 537 首 = 6 页）；开启后回复「第N页」「下一页」「上一页」翻阅；**默认关闭**（一次性完整展示）。对「我的歌单」与「歌单」搜索歌曲列表均生效 |

**管理员判定（使用 AstrBot 自带机制，无需在本插件配置）**：
1. AstrBot 配置页面（WebUI → 配置 → `admins_id` 管理员列表）中填写的 QQ
2. QQ 群主 / 群管理员
3. 其他支持 `is_admin()` 的平台管理员

不是管理员时，机器人会提示你前往 AstrBot 配置页面添加。

## 命令交互（@机器人触发）

| 指令 | 功能 | 需 Cookie | 权限 |
|---|---|---|---|
| `我的歌单` / `查看歌单` | 列出你的歌单 | 需要 | 仅管理员 |
| `歌单 关键词` / `歌单 歌单ID` | 搜索他人公开歌单，或按 ID 直达查看歌曲列表 | 不需要 | 管理员/白名单 |
| `点歌 歌名` 或 `点歌 歌手 - 歌名` | 搜索并列出结果（最多 20 条） | 不需要 | 管理员/白名单 |
| `封面 歌名` 或 `封面 歌手 - 歌名` | 发送该歌曲的封面图片 | 不需要 | 管理员/白名单 |
| `日推` / `今日推荐` | 列出今日推荐 | 需要 | 仅管理员 |
| 回复序号 | 选择歌单，或播放对应序号的歌曲 | — | 发起者本人 |
| 回复多个序号 | 一次播放多首（空格分隔，如 `1 7 98`） | — | 发起者本人 |
| 回复「第N页」 | 分页模式下翻阅歌单歌曲（如 `第3页`；也支持 `下一页` / `上一页`） | — | 发起者本人 |

所有列表均以**合并转发（聊天记录卡片）**形式发出：聊天界面只显示一个卡片，不占屏、不被 QQ 折叠拆分，点开后是完整的列表内容；**选歌列表的卡片头部会展示封面图（歌单用歌单封面，日推用第一首歌封面）**；歌单歌曲列表默认**一次性完整展示**（每 100 首为一条消息、超长自动分为多条），也可在配置中开启**分页模式**（每 100 首一页，回复「第N页」翻阅）；交互仅**发起者本人**可操作，其他人回复无效；播放成功后**自动撤回本次交互的全部菜单卡片**（NapCat 平台），超时退出时也会一并撤回并提示；交互等待超时 60 秒（歌单/日推/搜索），点歌超时默认 120 秒（可配置）。

## 使用示例（对话触发）

```
搜一下 周杰伦 的晴天
→ 工具返回歌曲列表，AI 排版展示

播放第 2 首
→ AI 调用 play_music 发送 QQ 音乐卡片

发一下晴天的封面
→ AI 调用 get_song_cover 发送歌曲封面图片

今天有什么推荐的歌？
→ 获取今日日推（需配置 Cookie + 管理员）

看看我的歌单
→ 获取个人歌单列表（需配置 Cookie + 管理员）

歌单 3778678
→ 按 ID 查看该歌单的完整歌曲列表（管理员）

歌单 华语流行
→ 搜索华语流行相关歌单，回复序号查看（管理员）

找找有没有适合跑步的歌单
→ AI 调用 search_playlists 返回歌单列表
```

| `search_music` | 搜索歌曲（歌名/歌手） | 不需要 | 管理员/白名单 |

| `get_song_cover` | 发送歌曲封面图片 | 不需要 | 管理员/白名单 |

| `get_daily_recommend` | 获取今日日推 | 需要 | 仅管理员 |

## 注意事项

- 仅**只读**操作，不会修改你的歌单/账号；「歌单」搜索与查看他人公开歌单同样不会产生任何修改
- 音乐卡片与封面图片在 NapCat / OneBot v11（aiocqhttp）平台以原生消息展示；其他平台自动降级为网易云链接
- 封面图来自网易云官方图床，需机器人所在网络可访问外网图片；**高/原图档位**会明显增加图片获取与发送耗时（部分原图可达数 MB）
- 超大歌单（千首级）首次加载完整曲目需要数秒；开启**分页模式**可改善浏览体验
- 搜索接口偶尔会返回其他歌手的同名歌曲，以搜索结果为准
- 请控制调用频率，避免触发网易云风控
