# 网易云音乐助手 (astrbot_plugin_ncm_daily)

网易云音乐个人助手：**搜索音乐、每日推荐、个人歌单**，支持发送 **QQ 音乐卡片**（群里可直接点击播放）。

- 搜索音乐无需任何配置，装上就能用
- 配置网易云 `MUSIC_U` Cookie 后，可获取**每日推荐**和**个人歌单**
- 纯标准库实现，**零第三方依赖**，Windows / Linux 通用

## 功能

| 能力 | 说明 | 需要 Cookie |
|---|---|---|
| 搜索音乐 | 按歌名/歌手搜索，返回歌曲列表 | ❌ |
| 音乐卡片 | 把歌曲以 QQ 音乐卡片形式发到群里/私聊（NapCat 渲染） | ❌ |
| 每日推荐 | 今日日推歌曲列表 | ✅ |
| 我的歌单 | 账号创建/收藏的歌单列表 | ✅ |
| 歌单详情 | 查看指定歌单的歌曲列表 | ❌ |

## 安装

从 Release 下载 zip，解压到 `AstrBot/data/plugins/`，然后在 WebUI 启用插件。

## 配置（可选）

1. 浏览器登录 [music.163.com](https://music.163.com)
2. 按 `F12` 打开开发者工具 → 切到 **Network（网络）** 面板
3. 随便点一个请求，在 **Request Headers → Cookie** 里找到 `MUSIC_U=xxxx`，复制 `xxxx` 部分
4. 在 AstrBot WebUI 的插件配置里填入 `music_u_cookie`

> ⚠️ 安全提示：MUSIC_U 相当于账号登录态，请勿分享给他人；失效后重新复制即可。

## 使用示例（对话触发）

```
搜一下 周杰伦 的晴天
→ 工具返回歌曲列表，AI 排版展示

播放第 2 首
→ AI 调用 play_music 发送 QQ 音乐卡片 🎵

今天有什么推荐的歌？
→ 获取今日日推（需配置 Cookie）

看看我的歌单
→ 获取个人歌单列表（需配置 Cookie）

打开歌单 3778678
→ 查看该歌单的歌曲列表
```

## 注意事项

- 仅**只读**操作，不会修改你的歌单/账号
- 音乐卡片仅支持 NapCat / OneBot v11（aiocqhttp）平台；其他平台自动降级为网易云链接
- 搜索接口偶尔会返回其他歌手的同名歌曲，以搜索结果为准
- 请控制调用频率，避免触发网易云风控
